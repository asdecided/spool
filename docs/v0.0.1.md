# v0.0.1 acceptance

## Purpose

Test a small local durable execution foundation on Tom's Omarchy XPS. No model account or API key is required. This version executes explicit offline commands, keeps their workspace and output, and prevents blind replay after an interruption.

## XPS acceptance

1. Record `omarchy-version`, `uname -a`, `rustc --version`, and `bwrap --version`.
2. Install from source using the README. Run `spool doctor` as your normal user. A namespace error is a blocker, not permission to run unsandboxed.
3. Run `bash scripts/xps-smoke.sh`. It prints the retained temporary directory. Check that `proof.txt` contains exactly `hello`, including after a second resume.
4. Inspect the timed-out job. Its state must be uncertain and a second resume must refuse it.
5. In another disposable directory create a job, queue `sh -c 'printf once >> proof.txt; sleep 60'` and resume it. While it is running, a second terminal's `spool status` in that same directory must report busy. Stop the first process with Ctrl+C. Run `spool recover`, inspect the job, and verify that `proof.txt` is not appended again. Confirm the sandbox process is gone before resolving the result.
6. Run the real sandbox integration test: `cargo test --locked --test sandbox -- --ignored`.

Keep this testing separate from valuable work. Never put secrets in arguments, checkpoints or output. Tests do not need access to your source tree or home directory.

## Installation from the release archive

Download `spool-v0.0.1-linux-x86_64.tar.gz` and its `.sha256` from [the v0.0.1 release](https://github.com/asdecided/spool/releases/tag/v0.0.1). In their download directory:

```bash
sha256sum -c spool-v0.0.1-linux-x86_64.tar.gz.sha256
tar -xzf spool-v0.0.1-linux-x86_64.tar.gz
mkdir -p "$HOME/.local/bin"
install -m755 spool-v0.0.1-linux-x86_64/spool "$HOME/.local/bin/spool"
export PATH="$HOME/.local/bin:$PATH"
spool --version
spool doctor
```

Runtime dependency: bubblewrap at `/usr/bin/bwrap`; Linux with enabled unprivileged namespaces. The executable uses bundled SQLite but dynamically links glibc. Only x86_64 Linux is packaged. Use source installation if the binary is incompatible. Remove `~/.local/bin/spool` to uninstall; preserve `.spool/` directories.

## Publication

The version-specific publication workflow tests and builds the release commit before creating a GitHub prerelease. The release includes the source revision and sandbox/Omarchy testing limits. See [published notes](../release/v0.0.1.md).

## Release scope

Spool v0.0.1 is a local Linux execution preview. Queue explicit commands, keep their workspace between runs, and inspect what happened after an interruption. Completed operations are skipped; uncertain ones stop for review.

This first version includes a SQLite operation journal, checkpoint history, exclusive workspace ownership, schema migration and offline bubblewrap execution with timeouts and capped captured output. It has no model loop, MCP integration or AsDecided decision integration yet. There are no workspace disk, memory or process-count quotas; use trusted commands and disposable workspaces.

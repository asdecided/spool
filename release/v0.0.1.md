Spool v0.0.1 is the first local Linux preview. Queue commands, keep their files between runs, and inspect what happened when work stops halfway through.

Completed commands stay completed. If Spool cannot establish an interrupted command's outcome, it stops for review instead of blindly running it again.

### Included

- Persistent jobs, JSON checkpoints and an SQLite operation journal.
- Offline bubblewrap execution with a separate workspace for each job.
- Queue, run, resume, inspect and explicit recovery commands.
- A 60-second default timeout and captured output capped at 64 KiB per stream.
- Linux x86_64 binary, SHA-256 checksum and an XPS smoke-test script.

### Install on Omarchy

```bash
sudo pacman -S --needed rust base-devel bubblewrap git
cargo install --git https://github.com/asdecided/spool.git --tag v0.0.1 --locked asdecided-spool
export PATH="$HOME/.cargo/bin:$PATH"
spool --version
spool doctor
```

This installs from any directory. For the prebuilt binary, download the archive and matching checksum below; follow the [archive instructions](https://github.com/asdecided/spool/blob/v0.0.1/docs/v0.0.1.md#installation-from-the-release-archive).

### What has been checked

Linux CI covers persistence, migration, exclusive ownership, four subprocess interruption points and real sandbox execution. Formatting and Clippy also pass. Live Omarchy XPS acceptance has not yet been confirmed.

### Early limits

This is an explicit-command execution foundation. Model-driven work, MCP and AsDecided decision integration are still to come. It has no disk, memory or process-count quotas; use trusted commands in disposable workspaces. Journal and output data are plaintext. Interrupted actions can leave partial files, and recovery does not roll them back.

Report install, sandbox or recovery problems in [Issues](https://github.com/asdecided/spool/issues), including `spool --version`, `bwrap --version`, `omarchy-version` and the error output.
